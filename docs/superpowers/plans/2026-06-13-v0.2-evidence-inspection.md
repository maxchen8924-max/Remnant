# v0.2 Evidence Inspection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the v0.2 developer-alpha evidence inspection loop so a local user can query a scope, receive a retrieval trace ID, and inspect the evidence behind that trace.

**Architecture:** Keep retrieval trace persistence as the source of truth, then expose a read-only trace evidence endpoint that enriches stored reranked chunk IDs with chunk, span, normalized message, and source artifact details. Wire the endpoint through Tauri IPC and replace the frontend evidence placeholder with a local trace inspector.

**Tech Stack:** Python 3.11/3.12, FastAPI, SQLite, pytest, Tauri 2, React, TypeScript, Vitest.
